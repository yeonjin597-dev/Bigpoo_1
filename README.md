## 3. 실행 순서
| 순서 | 명령 | 하는 일 | 결과 (out/) |
| --- | --- | --- | --- |
| 1 | `python lineage.py --fresh` | 원본 읽기 → 주소에서 지번·층 → 좌표 채우기 → 칸 계보 → 변수 | `analysis_table_v1.parquet`, `raw_parsed.pkl`, `lineage.pkl` |
| 2 | `python quality.py` | 품질 수치표, 변수 설명표 | `1125_품질수치표_코딩1.xlsx`, `변수설명표_analysis_table_v1.xlsx` |
| 3 | `python xcheck_floor.py` | 층 검증 (상가정보 대조) | `1125_층검증_상가정보대조.xlsx` |
| 3-1 | `python merge_external.py` | 외부변수 + 동시 영업 가게 수(max_concurrent) 붙이기 | `analysis_table_v2.parquet` |
| 3-2 | `python site_table.py` | 칸 테이블 (칸 1줄, 코딩 3 검증용) | `1126_칸테이블_v2.parquet`, `1126_칸테이블_열설명.xlsx` |
| 3-3 | `python kan_table.py` | **칸 테이블(가게 1행)** + `make_kan_table(df)` 함수 (휴게음식점 등 다른 업종에도 같은 규칙) | `1126_칸테이블_가게단위_일반음식점.parquet`, `1126_칸테이블_샘플100.csv` |

| 6 | `python score_transfer.py <판정1> [<판정2>]` | 양도 판정 채점 (**코딩 2 작성 예정**) | `1127_양도판정_채점.xlsx` |
| (구) | `python cox_models.py` | Cox M0~M4 (⚠ 아직 1차본, 같은 건물 층화 M3·M4가 느려서 개선 예정) | `1125_Cox_M0toM4_v0.xlsx` |

처음 1번은 `--fresh`로 원본부터 읽어야 해(몇 분). 그 다음부터는 `python lineage.py`만 해도 캐시를 써서 빠름.

## 5. 현재 주요 숫자 (2013~2022 개업 코호트 111,484곳)
- 이전 폐업 0/1/2/3/4+번 → 3년 안 폐업률 23.6 / 29.1 / 33.2 / 35.9 / 50.8%
- 2번 이상 / 0번 = 1.79배 (jari 정의 1.57, Parsa 정의 1.55)
- 좌표: 원본 91.2% + 같은 지번 6.7% + 상가정보 1.7% → 최종 결측 0.5%
- 층 검증(영업 중 가게): 1층 99.6%, 2층 이상 98.1% 일치 (n=35,447). 지하는 상가정보가 부정확해서 검증 불가

  이전 폐업 4번 이상 그룹의 88.6%가 이런 칸 → 칸 정의(한 층 = 한 자리)가 맞지 않는 곳. 처리 방식 결정 필요
